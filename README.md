# Cardora Marketplace

This package uses the uploaded working Cardora homepage as `index.html` without redesigning it.

## Included
- index.html — original working Cardora homepage
- about.html
- how-it-works.html
- sell-voucher.html
- faq.html
- contact.html
- trust.html
- privacy.html
- terms.html
- security.html

The homepage's existing API calls still expect the Cardora backend/server to be running.
